## 1. Project Overview

This project demonstrates the fundamentals of building a web server using Node.js and the Express.js framework.

The application creates an HTTP server that listens on port `3000` and responds to different HTTP GET requests. It provides a welcome message, displays student information in JSON format, returns the current date and time, and handles requests to unknown routes with a 404 response.

The project also demonstrates how to initialize a Node.js project, install dependencies, organize files, test routes, capture screenshots, and maintain source code using Git and GitHub.

## 6. Source Code

The complete application code is implemented in `app.js`.

```javascript
const express = require('express');

const app = express();

app.get('/', (req, res) => {
    res.send('Welcome to my server!');
});

app.get('/about', (req, res) => {
    res.json({
        name: 'K V KOWSHIKA BHARADWAJA',
        section: 'CSE-QE-2A / 113'
    });
});

app.get('/time', (req, res) => {
    res.send(new Date().toString());
});

app.use((req, res) => {
    res.status(404).send('Page not found');
});

app.listen(process.env.PORT || 3000, () => {
    console.log('Express server running on port 3000');
});
```

## 7. Explanation of the Code

### 7.1 Importing Express

```javascript
const express = require('express');
```

The `require()` function imports the Express package into the application. Express provides methods for creating a server and handling HTTP requests.

### 7.2 Creating an Express Application

```javascript
const app = express();
```

This creates an Express application instance. The `app` object is used to define routes and configure the server.

### 7.3 Home Route — GET `/`

```javascript
app.get('/', (req, res) => {
    res.send('Welcome to my server!');
});
```

- `app.get()` defines a route that handles HTTP GET requests.
- `/` represents the root or home route.
- `req` represents the incoming request.
- `res` represents the outgoing response.
- `res.send()` sends a text response to the client.

**Expected response:** `Welcome to my server!`

### 7.4 About Route — GET `/about`

```javascript
app.get('/about', (req, res) => {
    res.json({
        name: 'K V KOWSHIKA BHARADWAJA',
        section: 'CSE-QE-2A / 113'
    });
});
```

This route returns student details in JSON format.

- `app.get('/about', ...)` handles GET requests to `/about`.
- `res.json()` converts the JavaScript object into a JSON response.
- The response includes the student name and section.

### 7.5 Time Route — GET `/time`

```javascript
app.get('/time', (req, res) => {
    res.send(new Date().toString());
});
```

This route generates the current date and time whenever a request is received.

- `new Date()` creates a JavaScript Date object representing the current date and time.
- `.toString()` converts the date into a readable string.
- `res.send()` returns the string to the browser.

The displayed time depends on the computer's clock and time zone.

### 7.6 Handling Unknown Routes

```javascript
app.use((req, res) => {
    res.status(404).send('Page not found');
});
```

This middleware handles requests that do not match any of the routes defined above it.

- `app.use()` registers middleware.
- `res.status(404)` sets the HTTP status code to `404 Not Found`.
- `res.send()` returns the message `Page not found`.

This middleware is placed after the valid routes so that requests to unknown URLs receive the correct response.

### 7.7 Starting the Server

```javascript
app.listen(process.env.PORT || 3000, () => {
    console.log('Express server running on port 3000');
});
```

- `app.listen()` starts the Express server.
- `process.env.PORT` reads a port value from the environment when available.
- `3000` is the fallback port.
- The callback prints a confirmation message after the server starts listening.
