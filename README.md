## Description
This project demonstrates creating a web server using Node.js and Express.

## Installation
```bash
npm install
```

## Run the Server
```bash
npm start
```

The server runs on `http://localhost:3000`.

## Endpoints

| Method | Path | Description |
|---|---|---|
| GET | `/` | Displays a welcome message |
| GET | `/about` | Returns student details in JSON |
| GET | `/time` | Returns the current date and time |
| GET | `/hello123` | Example of a 404 response for an unknown path |
